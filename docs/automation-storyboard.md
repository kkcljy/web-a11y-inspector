A11Y Inspector 자동화 검사 스토리보드 (초안)

목표

기존 화면 단위 접근성 검사기를 확장하여 상품 가입 과정을 자동 또는
반자동으로 수행하고, 각 단계마다 접근성 검사를 실행한 뒤 최종
HTML/JSON/Excel 보고서를 생성한다.

역할

• GPT: 기능 기획, UX, 화면 구성, 접근성 가이드, 문서 작성
• Codex: 코드 구현, 리팩터링, 자동화 엔진, 테스트

전체 흐름

1. 자동화 검사 시작
2. 상품 선택
3. 실행 환경 선택 (Local / Dev / Test / Stage / Production)
4. 디바이스 선택 (PC / Mobile)
5. 실행 모드 선택
  • 더미 자동화
  • 반자동 검사
  • 안전 검사
6. 테스트 데이터 선택
7. 시나리오 확인
8. 자동화 실행
9. 단계별 접근성 검사
10. 최종 보고서 생성

실행 모드

더미 자동화

• 테스트계 전용
• 더미 데이터 사용
• 가입 완료까지 자동 수행

반자동 검사

• 본인인증 등에서 사용자 개입
• 이후 자동 진행

안전 검사

• 운영계용
• 민감정보 저장 금지
• 계약 직전 중단

자동화 실행 화면

• 현재 단계
• 진행률
• 실행 로그
• 단계별 접근성 결과
• 일시정지 / 재시도 / 건너뛰기

보고서

• 실행 요약
• 단계별 결과
• 문제 목록
• 수정 가이드
• HTML / JSON / Excel 출력

민감정보 정책

• 주민등록번호 저장 금지
• 인증번호 저장 금지

• 스크린샷 마스킹

• 로그 마스킹
